## 🇸🇦 1. النبذة التعريفية (اللغة العربية)

**نظام الدورات التدريبية** هو نظام ويب متكامل ومخصص لإدارة الأكاديميات والمعاهد التعليمية (مثل أكاديمية ترتيل لتعليم القرآن الكريم وعلومه). يهدف النظام إلى تسهيل عملية إدارة الدورات، تسجيل الطلاب، متابعة المدفوعات والرسوم الدراسية، وإصدار التقارير وإيصالات السداد بشكل احترافي ودقيق.

### 🌟 أبرز مميزات النظام:
1. **لوحة المعلومات (Dashboard):** عرض إحصائيات فورية تشمل عدد الطلاب، عدد الدورات النشطة، مدفوعات اليوم، مدفوعات الشهر، والرسوم المتبقية مع رسوم بيانية تفاعلية للمدفوعات اليومية.
2. **إدارة الطلاب:** إضافة بيانات الطلاب (الاسم، الرقم الوطني، الهاتف، البريد الإلكتروني)، مع ميزة البحث والفلترة السريعة وتوفير اختصار للتواصل المباشر عبر **واتساب**.
3. **إدارة الدورات التدريبية:** إنشاء الدورات وتحديد رسومها، تواريخ البداية والنهاية، وعدد الطلاب المسجلين مع إمكانية التعديل والحذف والبحث المتقدم.
4. **إدارة التسجيلات:** ربط الطلاب بالدورات التدريبية وتتبع حالة التسجيل (مؤكد، ملغي، إلخ) مع حساب الرسوم والمتبقي تلقائياً.
5. **إدارة المدفوعات والسداد:** تسجيل عمليات الدفع (نقدي / تحويل بنكي)، توليد أرقام إيصالات فريدة تلقائياً (مثل `INV-2026-0001`)، ومتابعة حالة الدفع (مدفوع كلياً، مدفوع جزئياً).
6. **التقارير وكشوفات الحساب:** تقارير مالية شاملة ومفصلة لكل طالب ودورة مع إمكانية الطباعة المباشرة.
7. **إيصالات السداد الرسمية:** طباعة إيصالات دفع رسمية تحمل شعار الأكاديمية ومعلومات الاتصال والعنوان وتوقيع الإدارة والختم.

## 🇬🇧 2. Overview (English)

**Tarteel Training Management System** is a comprehensive web-based application designed for educational academies and institutes (such as Tarteel Academy for Quranic Education). It streamlines course management, student registration, fee tracking, payment processing, and financial reporting.

### 🌟 Key Features:
1. **Dashboard:** Real-time statistics displaying total students, active courses, daily/monthly revenue, pending fees, and interactive charts for daily transactions.
2. **Student Management:** Manage student profiles (Name, National ID, Phone, Email), advanced search/filtering, and quick integration for **WhatsApp** communication.
3. **Course Management:** Create and configure training courses, set fees, define start/end dates, track enrolled students, and manage course lifecycles.
4. **Enrollment Management:** Link students to specific courses, monitor enrollment statuses, and dynamically calculate total, paid, and remaining balances.
5. **Payment & Receipt Management:** Record transactions (Cash / Bank Transfer), auto-generate receipt invoice numbers (e.g., `INV-2026-0001`), and track payment statuses (Partially/Fully Paid).
6. **Reports & Account Statements:** Detailed financial reports per student and course with a clean, printer-friendly layout.
7. **Official Payment Receipts:** Generate professional printable receipts complete with academy branding, contact details, signature lines, and official stamps.
